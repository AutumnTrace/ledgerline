## Idempotency check (write side, every command)

<details><summary>SQL</summary>

```sql

FROM (
    SELECT j.id, j.idempotency_key, j.player_id, j.posted_at, j.request_hash, j.reverses_entry_id, j.round_id, j.transaction_id, j.type

    WHERE j.idempotency_key = 'wallet:tx-424242'
```
